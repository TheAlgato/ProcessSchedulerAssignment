# 08 — A focused monitoring workspace

The dashboard now uses a compact workspace layout with navigation outside the live update area. Overview, Processes, and Analysis render separately, which keeps the selected view in place across refreshes. Process search, filtering and sorting are positioned above the table rather than mixed with device settings.

The sidebar holds appearance, refresh interval, history window, pause collection, and device details. Pausing freezes the last snapshot while allowing navigation and exports. Resuming permits the next due sample. Existing optional history and consent choices remain available.

Visual changes include flatter surfaces, smaller corner radii, consistent sans-serif typography, a restrained teal accent, shorter timestamps, and aligned chart colors. The chart hover display compares resources at the same time. The interface uses local fonts and no remote visual assets.
