# 10 — Black interface and welcome page

ProcessScope starts with a dedicated welcome page on a true black background. It introduces the app, explains the main tools and provides a single setup action. Collection controls stay out of the welcome page. The monitoring and history choices follow as separate screens with back navigation; no collector starts before onboarding is complete.

Black is the default dashboard appearance. The sidebar, controls and panels use near-black surfaces, fine borders and muted secondary text. The interface uses a high-contrast primary button and visible keyboard focus. An optional Light appearance switch remains in the sidebar. The monitoring status marker becomes gray while collection is paused.

The welcome flow, consent boundaries, default appearance, navigation and appearance control were checked with Streamlit's application runner, and the welcome/dashboard layouts were reviewed in the browser on macOS.
